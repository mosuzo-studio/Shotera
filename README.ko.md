## 캡처 이후의 작업을 위해

Shotera는 스크린샷을 설명하고 공유하거나 재사용할 수 있는 결과물로 바꿉니다. 제품 피드백, 버그 보고, 튜토리얼, 문서, 지원, 디자인 검토와 회의를 하나의 집중된 흐름으로 연결합니다.
<br/>
## 핵심 기능

- **스마트 정밀 캡처:** 창과 중첩 UI 요소를 감지하고 확대경과 픽셀 단위 제어로 선택 영역을 다듬습니다.
- **AI 이미지 편집:** AI 누끼로 피사체를 분리하고 AI 지우개로 불필요한 내용을 제거합니다.
- **오프라인 OCR과 이미지 번역:** 기기에서 복사 가능한 텍스트를 추출하고 이미지의 글자를 빠르게 번역합니다. 텍스트 추출을 위해 스크린샷을 업로드할 필요가 없습니다.
- **전문 주석과 개인정보 보호:** 화살표, 텍스트, 단계 번호, 확대, 모자이크와 가우시안 블러를 사용합니다.
- **데스크톱 고정과 프레젠테이션 모드:** `F3`으로 참고 자료를 고정하고 `Pause`로 데스크톱 방해 요소를 숨깁니다.

## 전체 기능

1. **캡처:** `F1`로 영역, 창, UI 요소 또는 전체 화면을 캡처하고 크기, 비율, 좌표, 지연과 프리셋을 설정합니다.
2. **AI 편집:** AI 누끼로 투명 이미지를 만들고 AI 지우개로 내용을 정리합니다.
3. **OCR과 번역:** 스크린샷, 이미지, 문서에서 텍스트를 로컬 추출하거나 이미지 텍스트를 번역합니다.
4. **주석과 가림:** 도형, 화살표, 텍스트, 그리기, 강조, 단계, 이모지와 확대경을 추가하고 모자이크나 블러로 가립니다.
5. **데스크톱 고정:** `F3`으로 캡처와 호환 클립보드 내용을 고정하고 투명도, 회전, 반전, 클릭 통과와 표시를 조절합니다.
6. **프레젠테이션 모드:** `Pause`로 아이콘과 방해 요소를 숨긴 뒤 이전 상태로 복원합니다.
7. **편집과 출력:** 이동, 크기 조절, 회전, 실행 취소와 다시 실행, 빠른 저장, 자동 저장과 여러 형식을 지원합니다.
8. **개인 설정:** 단축키, 언어, 글꼴, 시작 방식과 트레이 아이콘을 설정합니다.
<br/>
## 집중된 Windows 작업 흐름

`F1`을 눌러 대상을 선택하고 경계를 다듬은 뒤 주석 또는 이미지 처리를 적용하고 저장·공유하거나 `F3`으로 고정합니다.
<br/>
## 개인정보 보호와 제어

Shotera는 캡처를 로컬에 저장합니다. 오프라인 OCR은 기기에서 실행되므로 텍스트 추출을 위해 스크린샷을 업로드할 필요가 없습니다. 단축키, 언어, 글꼴, 시작 방식과 트레이 아이콘도 직접 설정할 수 있습니다. [개인정보 처리방침](https://shotera.mosuzo.com/privacy)을 확인하세요.
