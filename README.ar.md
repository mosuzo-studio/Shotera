## صُمم للعمل بعد لقطة الشاشة

يحوّل Shotera اللقطة إلى مادة جاهزة للشرح أو المشاركة أو إعادة الاستخدام، من تقارير الأخطاء والدروس إلى التوثيق والدعم والاجتماعات.
<br/>
## أبرز المزايا

- **التقاط ذكي ودقيق:** اكتشاف النوافذ وعناصر الواجهة وضبط التحديد على مستوى البكسل.
- **تحرير بالذكاء الاصطناعي:** عزل العناصر وإزالة المحتوى غير المرغوب فيه.
- **OCR دون اتصال وترجمة الصور:** استخراج النص على الجهاز وترجمة نص الصور دون رفع اللقطة لاستخراج النص.
- **تعليقات وحماية الخصوصية:** أسهم ونص وخطوات وتكبير وفسيفساء وتمويه.
- **تثبيت ووضع العرض:** استخدم `F3` للتثبيت و`Pause` لإخفاء مشتتات سطح المكتب.

## مجموعة الوظائف

1. **الالتقاط:** مناطق ونوافذ وعناصر أو شاشة كاملة عبر `F1` مع المقاس والنسبة والتأخير والقوالب.
2. **تحرير AI:** إنشاء صور شفافة وتنظيف المحتوى غير المرغوب.
3. **OCR والترجمة:** استخراج النص محلياً من الصور والمستندات أو ترجمة نص الصورة.
4. **التعليقات والإخفاء:** أشكال وأسهم ونص ورسم وخطوات وEmoji وتكبير وفسيفساء وتمويه.
5. **تثبيت سطح المكتب:** تثبيت اللقطات ومحتوى الحافظة عبر `F3` مع التحكم في الشفافية والدوران والظهور.
6. **وضع العرض:** إخفاء رموز سطح المكتب والمشتتات عبر `Pause` ثم استعادتها.
7. **التحرير والإخراج:** نقل وتحجيم وتدوير وتراجع وحفظ تلقائي وصيغ متعددة.
8. **التخصيص:** اختصارات ولغة وخطوط وبدء التشغيل وأيقونات النظام.
