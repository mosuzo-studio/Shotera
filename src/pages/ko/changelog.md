## Shotera v7.7.0

**출시일:** 2026-09-24

Lite 버전, 스크롤 캡처, 크기를 조절할 수 있는 고정 창, 그리고 더 가벼워진 빌드.

**🆚 Lite 버전과 전체 버전 차이:** 기능 차이는 [버전 비교](/ko/versions)에서 확인하세요.

**✨ 새로운 기능**

- Lite 버전 추가: 설치 프로그램이 17MB에 불과하며 핵심 스크린샷과 주석 기능을 담았습니다. 설정의 업그레이드 배너가 웹사이트의 전체 버전으로 연결됩니다.
- [Shotera 공식 웹사이트](https://shotera.mosuzo.com/)의 콘텐츠와 스타일을 새롭게 정비했습니다.
- 스크롤 캡처(미리 보기, 베타 테스트) 추가: 자동 스크롤과 수동 스크롤 두 가지 모드와 실시간 미리 보기 창을 제공합니다. 지능형 병합 알고리즘이 상단 경계를 감지하고 혼합 레이아웃을 처리합니다. 처음 사용할 때 안내 팁이 조작을 이끌어 줍니다. 베타 그룹에 참여해 테스트해 보세요.
- 고정 창 개선: 더블클릭으로 원래 크기와 '썸네일+닫기' 모드를 전환할 수 있습니다. 가장자리나 모서리를 드래그해 크기를 조절하며 종횡비는 고정됩니다. 네이티브 우클릭 메뉴가 창 경계를 넘어 표시됩니다. 도구 모음 표시 상태가 세션을 넘어 유지됩니다 ([#5](https://github.com/mosuzo-studio/Shotera/issues/5), [#7](https://github.com/mosuzo-studio/Shotera/issues/7), [#8](https://github.com/mosuzo-studio/Shotera/issues/8), [#9](https://github.com/mosuzo-studio/Shotera/issues/9), [#10](https://github.com/mosuzo-studio/Shotera/issues/10), [#14](https://github.com/mosuzo-studio/Shotera/issues/14)).
- AI 배경 제거 모델을 내장 u2netp로 바꿔 즉시 실행됩니다. rmbg-1.4는 이제 필요할 때 다운로드하며 첫 사용 시 안내를 제공합니다.
- 편집기에 인쇄 명령 추가: 우클릭 메뉴와 파일 메뉴에서 시스템 인쇄 대화 상자를 엽니다 ([#7](https://github.com/mosuzo-studio/Shotera/issues/7), [#8](https://github.com/mosuzo-studio/Shotera/issues/8)).
- 편집기 우클릭 메뉴에서 현재 파일을 선택한 상태로 파일이 있는 폴더를 열 수 있습니다 ([#9](https://github.com/mosuzo-studio/Shotera/issues/9), [#10](https://github.com/mosuzo-studio/Shotera/issues/10)).

**🚀 개선 사항**

- 빌드 크기 20% 감소: 설치 프로그램 압축과 컴파일러 설정을 최적화했습니다. 더 빠르게 반복 빌드할 수 있는 FastBuild 프로필도 추가했습니다.
- 기본 메모리 사용량을 줄였습니다.
- 편집기 제목 표시줄에 현재 이미지 파일 이름이 동적으로 표시됩니다.
- 업데이트 성공 알림을 로고 + 텍스트 + 버튼으로 간소화하고 큰 미리 보기를 없앴습니다.
- 온보딩 흐름 개선: 8페이지 가이드는 오른쪽 아래 초대 카드에서 열립니다. 새 기능 소개 창은 닫은 횟수가 3회에 도달하면 더 이상 표시되지 않습니다. AI 배경 제거는 첫 사용 시 안내를 표시합니다.
- AI 이미지 번역에서 번역문이 원문과 같으면 경고하고 언어 설정으로 안내합니다. 경고는 '설정 → AI 기능'에서 끌 수 있습니다.
- 스크린샷, 스크롤 캡처, 편집기 출력의 기본 파일 이름을 `Shotera_YYYYMMDD_HHMMSS`로 통일했습니다.
- 스크롤 캡처 알림의 썸네일이 전체 이미지를 눌러 놓는 대신 상단 화면을 잘라 표시합니다.

**🐞 버그 수정**

- 듀얼 모니터 환경에서 주석 창의 초기 위치가 잘못 지정되는 문제를 수정했습니다.
- 고정 창 드래그 크기 조절 시 비율 계산 오류와 테두리 흔들림 문제를 수정했습니다.
- 선택 후 더블클릭 동작이 적용되지 않고 원래 크기로 돌아가지 않는 문제를 수정했습니다.
- 스크롤 캡처 병합 실패 대화 상자가 클릭 통과 규칙에 막혀 클릭할 수 없던 문제를 수정했습니다.
- 편집기에서 이미지를 불러온 후 유령 스크롤 막대가 나타나고 확대/축소가 0% 또는 1%로 표시되는 문제를 수정했습니다.
- 편집기 제목 표시줄에 파일 이름이 중복 표시되는 문제를 수정했습니다.

**🙏 감사의 말**

문제를 알려 주시고 기능을 제안해 주신 커뮤니티 여러분께 감사드립니다. 여러분의 의견이 이번 릴리스를 만들었습니다. 스크롤 캡처와 고정 창 개선은 사용자 피드백에서 비롯되었습니다.

## Shotera v7.6.0

**출시일:** 2026-09-21

새 기능 소개 창, QR 코드 인식, GIF 재생, 그리고 더 많은 이미지 형식 지원.

**✨ 새로운 기능**

- 시작 시 새 기능 소개 창 추가: 두 가지 캡처 완료 모드를 비교하고, QR 코드 인식의 위치를 알려 주며, Shotera 평가를 요청합니다. '다시 표시하지 않기'를 선택하거나 '확인'을 세 번 클릭하면 더 이상 표시되지 않습니다.
- QR 코드 인식 추가: Micro QR, Data Matrix, Aztec, PDF417, Code128, EAN13, Code39, ITF, UPCA와 GS1 디지털 링크를 지원합니다. 결과 패널은 크기 조절과 드래그가 가능하며 번호가 붙은 기록을 보여 줍니다.
- PNG, JPG, JPEG, WebP, BMP, GIF, SVG, ICO, AVIF, TIFF(tif/tiff)를 열 수 있습니다. SVG, ICO, AVIF, TIFF는 이번 릴리스에서 새로 추가되었습니다. 파일 메뉴에서 열거나 이미지를 끌어다 놓을 수 있습니다.
- GIF 애니메이션 재생 추가. 상태 표시줄과 이미지 정보 패널에 프레임 수와 총 재생 시간을 표시합니다.
- 이미지 정보 패널 추가: 크기, 형식, DPI, 색상 모드, 비트 심도, EXIF 촬영 정보, 그리고 작성자와 GPS 태그에 대한 개인정보 검사를 표시합니다. 파일 메뉴, 캔버스 우클릭, 상태 표시줄 또는 Ctrl+I로 열 수 있습니다.
- 상태 표시줄에 확대/축소 비율, 이미지 크기, 파일 크기, 파일 경로를 표시합니다. 경로 표시는 숨김, 경로 표시, 전체 경로 세 가지 모드입니다.
- 편집기 제목 표시줄에 현재 이미지 이름을 표시합니다. 캔버스 우클릭 메뉴에서 현재 파일을 선택한 상태로 파일이 있는 폴더를 열 수 있습니다 ([#1](https://github.com/mosuzo-studio/Shotera/issues/1)).
- 파일을 덮어쓰기 전에 확인 대화 상자를 추가했습니다. '다시 묻지 않기'를 선택하면 이후에는 건너뜁니다.
- 고정 창: 우클릭 메뉴에서 오른쪽 위 도구 모음을 숨길 수 있으며 설정이 기억됩니다 ([#4](https://github.com/mosuzo-studio/Shotera/issues/4)).

**🚀 개선 사항**

- 화면 상단의 모드 바를 다시 표시해 '스크린샷'과 'QR 코드' 진입점을 제공합니다.
- 편집기의 대용량 이미지 렌더링을 재작업해 불러오기와 확대/축소가 부드럽고 유연해졌습니다.
- Ctrl+휠 확대/축소가 캔버스 중앙이 아니라 커서를 기준으로 동작합니다.
- 확대/축소 단축키 추가: Ctrl+=, Ctrl+-, Ctrl+0.
- 확대/축소와 이동 후에도 이미지가 화면 밖으로 완전히 벗어나지 않습니다.
- 편집기 이미지에 부드러운 그림자를 추가하고 라이트 모드에서는 순백색 캔버스를 사용합니다.
- 색상 추출 돋보기 재설계: 사각형 이중 테두리, 더 좁힌 패널 테두리, 사각형 색상 견본, 조정된 십자선 색상.
- 도움말 메뉴에서 공식 웹사이트를 바로 엽니다.
- AI 이미지 번역에서 번역문이 원문과 같을 때(보통 대상 언어가 원본 언어와 같을 때) 경고하고 언어 설정으로 안내합니다. '설정 → AI 기능'에서 이 알림을 끌 수 있습니다.
- 평가 요청 시점 조정: 각 버전에서 첫 캡처 후 한 번 표시되고, 이후에는 한 달에 최대 한 번 표시됩니다.

**🐞 버그 수정**

- 이미지를 불러온 후 유령 스크롤 막대가 나타나고 확대/축소가 0% 또는 1%로 잘못 표시되는 문제를 수정했습니다.
- 편집기 '파일' 드롭다운이 창 가장자리에서 잘리는 문제를 수정했습니다.
- Windows 시작 시 앱이 예기치 않게 스크린샷을 실행하는 문제를 수정했습니다.
- 새 기능 소개 창에서 캡처 완료 모드를 변경해도 설정에 반영되지 않는 문제를 수정했습니다.

**🙏 감사의 말**

이번 릴리스를 만든 기능 제안을 해 주신 @korenevskiy, @NewJon27님께 감사드립니다.

QR 코드 인식은 헤비 유저 Horihons님의 피드백에 따라 추가했습니다.

## Shotera v7.5.1

**출시일:** 2026-09-14

우아한 캡처 모드, 즉시 고정, 복사 단축키.

**✨ 새로운 기능**

- '우아하고 간결' 캡처 모드 추가: 영역을 선택하면 끝입니다. 이미지가 복사되고 알림 미리 보기가 표시됩니다. 오버레이가 없습니다. 다크 모드도 지원합니다 ([#1](https://github.com/mosuzo-studio/Shotera/issues/1)).
- 캡처 중이나 캡처 후에 사용할 수 있는 F3 즉시 고정 단축키를 추가했습니다. '설정 → 단축키'에서 사용자 지정할 수 있습니다 ([#3](https://github.com/mosuzo-studio/Shotera/issues/3), [#4](https://github.com/mosuzo-studio/Shotera/issues/4)).
- Ctrl+C로 스크린샷 복사와 오버레이 닫기를 한 번에 수행합니다.
- 더블클릭으로 스크린샷을 즉시 확정할 수 있습니다.
- 우클릭으로 스크린샷을 취소할 수 있습니다.
- '스크린샷 후 텍스트 자동 추출' 스위치를 '설정 → 캡처'에 추가했습니다.
- 편집기 창 제목 표시줄이 시스템 테마를 따릅니다.

**🚀 개선 사항**

- 편집기 '다른 이름으로 저장'이 동적 타임스탬프를 파일 이름으로 사용합니다.
- '다른 이름으로 저장'에 Ctrl+Shift+S 단축키를 추가했습니다.
- 트레이 메뉴와 편집기 창 제목이 현지화되었습니다.

**🐞 버그 수정**

- 영어가 아닌 설치 경로에서 OCR이 실패하는 문제를 수정했습니다.
- 고 DPI 디스플레이에서 고정 이미지의 해상도가 낮아지는 문제를 수정했습니다.
- F3가 선택 영역과 클립보드에서 고정 창을 중복 생성하는 문제를 수정했습니다.
- Microsoft Store 버전에서 '우아하고 간결' 모드의 알림이 표시되지 않는 문제를 수정했습니다.
- Microsoft Store 버전에서 알림을 클릭하면 추가 스크린샷이 실행되는 문제를 수정했습니다.
- 업그레이드 후에도 업데이트 버튼의 빨간 점이 남아 있는 문제를 수정했습니다.

**🙏 감사의 말**

이번 릴리스를 만든 기능 제안을 해 주신 @Const-me, @LightQuanta, @wherewhere님께 감사드립니다.

## Shotera v7.5.0

**출시일:** 2026-09-12

완전한 이미지 편집기, 캡처 모드, 확장된 CPU 지원.

**✨ 새로운 기능**

- 트레이의 '이미지 편집…'에서 열 수 있는 완전한 이미지 편집기를 추가했습니다. 열기/저장/다른 이름으로 저장, 드래그 앤 드롭, Ctrl+휠 10%-400% 확대/축소, 주석 도구, OCR, AI 배경 제거, AI 지우기를 지원합니다.
- 화살표 하위 도구 모음에 '기본 화살표' 테이퍼 화살표 스타일을 추가했습니다.
- '캡처 완료 모드' 설정 추가: '우아하고 간결'을 선택하면 선택 영역을 복사하고 알림 미리 보기를 표시하며(클릭하면 편집기가 열림), 기본값인 '바로 주석 달기'를 유지할 수도 있습니다.
- '스크린샷 후 텍스트 자동 추출'과 'AI 기능 입구 숨기기' 설정을 추가했습니다.
- 번역 대상 언어가 인터페이스 언어를 따릅니다.

**🚀 개선 사항**

- CPU 지원을 Intel 3세대(Ivy Bridge) 이전까지 확장했습니다. 구형 CPU에서는 AI 기능을 사용할 수 없으며 설명 대화 상자가 표시됩니다.
- Windows 알림이 꺼져 있으면 오른쪽 아래에 자체 안내 창을 표시합니다.
- 지우개로 화살표/선을 지울 수 있으며 지우개 커서가 표시됩니다.
- 주 도구 모음을 메뉴 바에 넣어 항상 표시합니다. 보조 도구 모음은 더 이상 이미지를 밀어내지 않습니다.
- 편집기에서 복사해도 창이 닫히거나 선택이 해제되지 않습니다. 빨간 ✕는 이미지를 지웁니다.
