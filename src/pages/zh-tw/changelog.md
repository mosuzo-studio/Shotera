## Shotera v7.7.0

**發布日期:** 2026-09-24

Lite 版、長截圖、可縮放的釘圖，以及更輕量的建置。

**🆚 Lite 版與完整版差異：** 詳見[版本對比](/zh-tw/versions)。

**✨ 新增功能**

- 新增 Lite 版：安裝程式僅 17MB，包含核心截圖與標註功能。設定頁的升級橫幅連結至官網的完整版。
- [Shotera 官方網站](https://shotera.mosuzo.com/)內容與樣式更新。
- 新成長截圖（預覽版、Beta 測試）：提供自動與手動滾動兩種模式，附即時預覽小窗。智慧拼接演算法會偵測頂部邊界並處理混合版面。首次使用有教學提示引導操作。歡迎加入測試團隊體驗。
- 釘圖視窗增強：雙擊可在原始尺寸與縮圖+關閉模式之間切換。拖曳邊緣或四角調整尺寸，並鎖定長寬比。原生右鍵選單可超出視窗邊界。工具列顯示狀態可跨工作階段保留 ([#5](https://github.com/mosuzo-studio/Shotera/issues/5), [#7](https://github.com/mosuzo-studio/Shotera/issues/7), [#8](https://github.com/mosuzo-studio/Shotera/issues/8), [#9](https://github.com/mosuzo-studio/Shotera/issues/9), [#10](https://github.com/mosuzo-studio/Shotera/issues/10), [#14](https://github.com/mosuzo-studio/Shotera/issues/14))。
- AI 去背模型改用內建 u2netp，速度極快。rmbg-1.4 改為隨需下載，首次使用附引導說明。
- 編輯器新增列印指令：右鍵選單與「檔案」選單可開啟系統列印對話框 ([#7](https://github.com/mosuzo-studio/Shotera/issues/7), [#8](https://github.com/mosuzo-studio/Shotera/issues/8))。
- 編輯器右鍵選單可開啟檔案所在資料夾，並醒目顯示目前的檔案 ([#9](https://github.com/mosuzo-studio/Shotera/issues/9), [#10](https://github.com/mosuzo-studio/Shotera/issues/10))。

**🚀 改進優化**

- 建置產物整體縮小 20%：安裝程式壓縮與編譯器設定經過最佳化。另新增 FastBuild 快速建置設定檔。
- 降低基礎記憶體用量。
- 編輯器標題列會動態顯示目前的圖片檔名。
- 更新成功通知簡化為 logo + 文字 + 按鈕，移除大圖預覽。
- 引導流程調整：8 頁導覽改由右下角邀請卡進入。新功能介紹視窗累計關閉 3 次後不再顯示。AI 去背首次使用時顯示引導提示。
- AI 圖片翻譯在譯文與原文相同時提出警告，並引導至語言設定。此警告可在「設定 → AI 能力」中關閉。
- 截圖、長截圖與編輯器輸出的預設檔名統一為 `Shotera_YYYYMMDD_HHMMSS`。
- 長截圖通知的縮圖改為裁切頂部檢視範圍，不再將整張圖片壓扁。

**🐞 問題修復**

- 修正雙螢幕環境下標註視窗初始定位錯誤。
- 修正釘圖視窗拖曳縮放的比例計算錯誤與邊框抖動。
- 修正雙擊行為在選取後未生效，且無法返回原始尺寸。
- 修正長截圖拼接失敗對話框被點擊穿透規則擋住。
- 修正編輯器載入圖片後出現幽靈捲軸與 0%/1% 縮放顯示。
- 修正編輯器標題列顯示重複檔名。

**🙏 致謝名單**

感謝回報問題與提出功能建議的社群成員，這些意見塑造了本次版本。長截圖與釘圖視窗的增強由使用者回饋推動。

## Shotera v7.6.0

**發布日期:** 2026-09-21

新功能介紹視窗、QR Code 辨識、GIF 動圖播放，以及更多圖片格式支援。

**✨ 新增功能**

- 新增啟動時的新功能介紹視窗：比較兩種截圖完成模式、說明 QR Code 辨識的位置，並邀請你為 Shotera 評分。勾選「不再顯示」，或點選「知道了」累計三次，即不再顯示。
- 新增 QR Code 辨識：支援 Micro QR、Data Matrix、Aztec、PDF417、Code128、EAN13、Code39、ITF、UPCA，以及 GS1 數位連結。結果面板可調整尺寸、可拖曳，並附編號歷史記錄。
- 可開啟 PNG、JPG、JPEG、WebP、BMP、GIF、SVG、ICO、AVIF 與 TIFF（tif/tiff）。其中 SVG、ICO、AVIF、TIFF 為本版新增。可從「檔案」選單開啟，或直接拖入圖片。
- 新增 GIF 動畫播放。狀態列與「圖片資訊」面板會顯示影格數與總時長。
- 新增「圖片資訊」面板：尺寸、格式、DPI、色彩模式、位元深度、EXIF 拍攝資訊，以及作者與 GPS 標籤的隱私檢查。可透過「檔案」選單、畫布右鍵、狀態列或 Ctrl+I 開啟。
- 狀態列顯示縮放比例、圖片尺寸、檔案大小與檔案路徑。路徑顯示提供三種模式：隱藏、麵包屑與完整路徑。
- 編輯器標題列顯示目前的圖片名稱。畫布右鍵選單可開啟檔案所在資料夾，並醒目顯示目前的檔案 ([#1](https://github.com/mosuzo-studio/Shotera/issues/1))。
- 儲存覆寫檔案前新增確認對話框。勾選「不再詢問」即可日後略過。
- 釘圖視窗：可從右鍵選單隱藏右上角工具列，且設定會被記住 ([#4](https://github.com/mosuzo-studio/Shotera/issues/4))。

**🚀 改進優化**

- 頂部模式列恢復顯示，提供「截圖」與「QR Code」入口。
- 編輯器的大圖算繪機制重新設計——載入與縮放現在順暢流利。
- Ctrl+滾輪縮放改以游標為錨點，不再固定以畫布中心為準。
- 新增縮放快速鍵：Ctrl+=、Ctrl+-、Ctrl+0。
- 縮放與平移後，圖片不再完全移出可視範圍。
- 編輯器圖片加上柔和陰影，淺色模式使用純白畫布。
- 取色放大鏡重新設計：方形雙層描邊、面板邊框收緊、色票改為方形，並重新調校十字線顏色。
- 「說明」選單可直接開啟官網。
- AI 圖片翻譯在譯文與原文相同時（通常是目標語言與來源語言相同）提出警告，並引導至語言設定。可在「設定 → AI 能力」中關閉此提示。
- 評分提示的出現時機重新調整：改為在每個版本的首次截圖後出現，之後每月最多一次。

**🐞 問題修復**

- 修正載入圖片後出現幽靈捲軸，以及縮放比例顯示為 0% 或 1%。
- 修正編輯器「檔案」下拉面板被視窗邊緣裁切。
- 修正應用程式隨 Windows 啟動時誤觸截圖。
- 修正從新功能介紹視窗變更截圖完成模式後，設定頁仍顯示舊選項。

**🙏 致謝名單**

感謝 @korenevskiy 與 @NewJon27 提出的功能建議，這些建議塑造了本次版本。

QR Code 辨識是應重度使用者 Horihons 的意見回饋而新增。

## Shotera v7.5.0

**發布日期:** 2026-09-12

完整圖片編輯器、擷取模式、擴充的 CPU 支援。

**✨ 新增功能**

- 新增完整圖片編輯器，可從系統匣「編輯圖片…」開啟。支援開啟/儲存/另存新檔、拖放、Ctrl+滾輪縮放 10%-400%、標註工具、OCR、AI 去背、AI 擦除。
- 在箭頭子工具列新增「樸素箭頭」錐形箭頭樣式。
- 新增「截圖完成模式」設定：選擇「優雅簡潔」可複製選取範圍並顯示通知預覽（點擊開啟編輯器），或維持「所見即所得」預設模式。
- 新增「截圖後自動擷取文字」與「隱藏 AI 功能入口」設定。
- 翻譯目標語言跟隨介面語言。

**🚀 改進優化**

- CPU 支援擴展至 Intel 第三代（Ivy Bridge）及更早。較舊的 CPU 上 AI 功能無法使用，並會顯示說明對話框。
- 停用 Windows 通知時，在右下角自繪引導視窗。
- 橡皮擦現在可擦除箭頭/線條，並顯示橡皮擦游標。
- 主工具列嵌入選單列，隨時可見。副工具列不再推擠圖片。
- 在編輯器中複製不再關閉視窗或清除選取範圍。紅色 ✕ 可清除圖片。
- 設定中的「截圖」頁面以紅點標示新功能。

**🐞 問題修復**

- 修正不支援 AVX2 的 CPU 啟動時應用程式崩潰。
- 修正中文/非英文安裝路徑下 OCR 失敗。
- 修正包含非 ASCII 路徑字元的圖片無法透過拖放載入。
- 修正編輯器視窗有時無法從通知載入截圖。
- 修正 AI 去背/擦除後留下位移影像與未清除條紋。
- 修正編輯器狀態列在圖片載入後未更新。
- 修正編輯器中文字擷取醒目提示位移。
- 修正數字/表情貼圖調整尺寸時向下漂移。

**🗑️ 移除內容**

- 編輯器選單列中的「編輯」與「檢視」選單。

## Shotera v7.3.0

- 修正取消標註工具時未鎖定已繪製的圖形。

## Shotera v7.2.0

**發布日期:** 2026-08-02

更快的擷取啟動、自訂擷取、15 種語言。
