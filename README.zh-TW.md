## 為擷取之後的工作而生

Shotera 讓螢幕擷取從「捕捉」直接變成「可用」。無論是產品回饋、錯誤報告、教學、文件、客戶支援、設計審查或會議簡報，都能在一套專注的流程中完成擷取、編輯、文字擷取與桌面參考。

<br/>

## 核心亮點

- **智慧精準擷取：** 自動辨識視窗與巢狀介面元素，搭配放大鏡與像素級調整精準選取。
- **AI 圖像處理：** 使用 AI 去背分離主體，並以 AI 擦除移除不需要的內容。
- **離線 OCR 與圖片翻譯：** 在裝置上擷取可複製文字，並快速翻譯圖片中的文字，擷取文字時無須上傳螢幕截圖。
- **專業標註與隱私保護：** 使用箭頭、文字、步驟編號、局部放大、馬賽克與高斯模糊，清楚說明並保護敏感資訊。
- **桌面貼圖與簡報模式：** 按 `F3` 將內容固定在最上層；按 `Pause` 可在會議或展示前隱藏桌面干擾項目。

## 完整功能

1. **螢幕擷取：** 按 `F1` 擷取區域、視窗、介面元素或全螢幕，並可設定固定尺寸、比例、座標、延遲與常用預設。
2. **AI 圖像處理：** 使用 AI 去背製作透明背景素材，並透過 AI 擦除清理不需要的內容。
3. **OCR 與翻譯：** 在本機從螢幕截圖、圖片與文件提取可複製文字，或翻譯圖片中的文字。
4. **標註與遮蔽：** 加入圖形、箭頭、文字、手繪、螢光標記、步驟編號、Emoji 與局部放大；以馬賽克或高斯模糊遮蔽敏感資訊。
5. **桌面貼圖：** 按 `F3` 固定螢幕截圖或剪貼簿中的相容圖片、文字與色彩，並調整透明度、旋轉、翻轉、滑鼠穿透與顯示狀態。
6. **簡報模式：** 按 `Pause` 清除會議或展示時的桌面圖示與干擾，結束後恢復原本狀態。
7. **編輯與輸出：** 移動、縮放、旋轉與調整標註樣式，支援復原與重做、快速儲存、自動儲存、檔名範本及多種圖片格式。
8. **個人化：** 自訂快捷鍵、介面語言、字型、啟動方式與系統匣圖示。

<br/>

## 專注的 Windows 工作流程

1. 按 `F1`，選擇自由區域、視窗、介面元素或全螢幕。
2. 使用智慧介面辨識與擷取放大鏡微調邊界。
3. 依需求進行標註、遮蔽、文字擷取、翻譯或 AI 圖像處理。
4. 儲存或分享成果，也可按 `F3` 將內容留在桌面上參考。

## 隱私與掌控

Shotera 將螢幕截圖儲存在本機。離線 OCR 直接在裝置上執行，提取文字時無須上傳螢幕截圖。你也能自訂快捷鍵、介面語言與字型、啟動方式和系統匣圖示，掌控自己的使用方式。

詳情請閱讀[隱私權政策](https://shotera.mosuzo.com/privacy)。
